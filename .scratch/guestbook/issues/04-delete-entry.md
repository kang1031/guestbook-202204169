# 04: 글 삭제

**What to build:** 글쓴이가 글 카드에서 "삭제"를 누르면 카드 안에 비밀번호 입력란과 삭제 버튼이 열린다. 비밀번호가 맞으면 **글(Entry)** 이 완전히 삭제되어 목록에서 사라진다. 추가 확인 창은 없다. 비밀번호가 틀리면 삭제가 거부되고 그 사실이 카드 안에 표시된다. 이미 삭제된 글이면 "이미 삭제된 글입니다"가 표시되고 목록이 새로 고쳐진다.

**Blocked by:** 02 (글 작성). 03과 동시에 진행할 수 있다. 다만 둘 다 글 카드 컴포넌트를 건드리므로 순서대로 병합한다.

**Status:** ready-for-agent

- [ ] 방명록 모듈에 글 삭제 동작이 있고, 결과를 `ok`, `wrong-password`, `not-found` 중 하나로 돌려준다
- [ ] 완전 삭제(`DELETE`)이다. 비밀번호 확인과 삭제 사이에 글이 지워져 영향 행 수가 0이면 `not-found`로 처리한다
- [ ] 카드에 삭제 모드가 있고, "취소"로 보기 모드로 돌아갈 수 있다
- [ ] `wrong-password`면 카드 안에 안내가 나오고 글은 남는다
- [ ] `not-found`면 비밀번호 오류와 다른 안내가 나오고, 목록이 재검증된다
- [ ] 제출하는 동안 버튼이 비활성화된다
- [ ] Vitest: 맞는 비밀번호로 삭제하면 목록에서 사라짐, 틀린 비밀번호면 `wrong-password`이고 글이 남음, 없는 id면 `not-found`, 이름은 같고 비밀번호가 다른 두 글은 서로의 비밀번호로 삭제되지 않음
- [ ] `npm run lint`, `npm test`, `npm run build`가 통과한다

# 03: 메시지 수정

**What to build:** 글쓴이가 글 카드에서 "수정"을 누르면 카드 안에 현재 **메시지(Message)** 가 채워진 입력창과 비밀번호 입력란이 열린다. 새 메시지와 비밀번호를 한 번에 저장한다. 비밀번호가 맞으면 메시지가 바뀌고, "(수정됨)"과 수정 시각이 붙는다. 목록 순서는 바뀌지 않는다. 비밀번호가 틀리면 수정이 거부되고 "비밀번호가 일치하지 않습니다"가 카드 안에 표시되며, 고쳐 쓴 메시지는 입력창에 남는다. 이미 삭제된 글이면 "이미 삭제된 글입니다"가 표시되고 목록이 새로 고쳐진다. 작성자 이름은 수정할 수 없다.

**Blocked by:** 02 (글 작성)

**Status:** done

- [x] 방명록 모듈에 메시지 수정 동작이 있고, 결과를 `ok`, `invalid`, `wrong-password`, `not-found` 중 하나로 돌려준다
- [x] 비밀번호는 `timingSafeEqual`로 비교한다. 비밀번호 확인과 갱신 사이에 글이 지워져 영향 행 수가 0이면 `not-found`로 처리한다
- [x] 성공하면 `updatedAt`이 채워지고, 카드에 "(수정됨)"과 서울 기준 수정 시각이 표시된다
- [x] 카드는 보기 모드와 수정 모드를 오간다. "취소"를 누르면 아무것도 바꾸지 않고 보기 모드로 돌아간다
- [x] `wrong-password`면 카드 안에 안내가 나오고, 입력한 메시지가 유지된다
- [x] `not-found`면 비밀번호 오류와 다른 안내가 나오고, 목록이 재검증된다
- [x] 제출하는 동안 버튼이 비활성화된다
- [x] Vitest: 맞는 비밀번호로 수정하면 반영되고 순서는 유지됨, 틀린 비밀번호면 `wrong-password`이고 메시지는 그대로임, 없는 id면 `not-found`, 메시지 검증 경계값, 이름은 같고 비밀번호가 다른 두 글은 서로의 비밀번호로 수정되지 않음
- [x] `npm run lint`, `npm test`, `npm run build`가 통과한다

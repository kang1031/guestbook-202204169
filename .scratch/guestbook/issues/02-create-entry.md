# 02: 글 작성

**What to build:** 방문자가 작성 폼에 작성자 이름, 메시지, 비밀번호를 입력해 보내면 새 **글(Entry)** 이 목록 맨 위에 나타난다. 입력이 규칙에 맞지 않으면 해당 칸 옆에 이유가 표시되고, 입력한 내용은 그대로 남는다. 저장에 성공하면 메시지와 비밀번호 칸은 비워지고 이름 칸은 남는다. 비밀번호는 원문으로 저장되지 않는다.

**Blocked by:** 01 (방명록 골격과 글 목록 조회)

**Status:** done

- [x] 방명록 모듈에 글 작성 동작이 있고, 결과를 `ok` 또는 `invalid`(필드별 오류 포함)로 돌려준다
- [x] 검증 규칙: 이름은 앞뒤 공백을 제거한 뒤 1~20자, 메시지는 앞뒤 공백을 제거한 뒤 1~500자(내부 줄바꿈 유지), 비밀번호는 4~72자(공백 제거 안 함)
- [x] 비밀번호는 `crypto.scrypt`와 글마다 다른 salt로 해시해 저장하고, 해시는 어떤 반환값에도 포함되지 않는다
- [x] 작성 Server Action이 모듈을 호출하고, 성공하면 목록을 재검증한다
- [x] 작성 폼은 제출하는 동안 버튼을 비활성화하고 처리 중임을 표시한다
- [x] 성공하면 메시지와 비밀번호 칸이 비워지고 이름 칸은 유지된다. 실패하면 입력 내용이 모두 유지된다
- [x] 비밀번호 입력란은 `type="password"`이다
- [x] Vitest: 작성 후 목록 맨 위에 나타남, 검증 경계값(0자, 공백만 입력, 20/21자, 500/501자, 비밀번호 3/4/72/73자), 반환값에 해시가 없음
- [x] `npm run lint`, `npm test`, `npm run build`가 통과한다
